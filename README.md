# Generator Gambar 2D

Aplikasi web untuk menghasilkan gambar 2D menggunakan AI.

## Cara Menjalankan

```bash
npm install
npm start
```

Setelah server berjalan, buka browser ke `http://localhost:3000`.

## Struktur Project

```
project/
│
├── public/
│   ├── index.html   # Halaman utama
│   ├── style.css    # Styling
│   └── script.js    # Logika frontend
│
├── server.js         # Backend Express (menyajikan folder public)
├── package.json
├── .env.example
├── .gitignore
└── README.md
```
